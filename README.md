# 📝 Publications

### 2026

**Embark Now: User Demand Oriented Framework for Multi-day Urban Travel Itinerary Planning**

Rongbo Qi, Yaqi Zhang, **Shijun Yan**, Xuemeng Liu, Xiangrui Cai, Chunyao Song

*arXiv preprint, 2026*

This work studies personalized multi-day urban travel itinerary planning by integrating **Large Language Models (LLMs)** with an enhanced **Greedy Randomized Adaptive Search Procedure (GRASP)**. The framework captures user preferences from natural-language requests and generates feasible personalized itineraries under real-world spatiotemporal constraints.

# 📦 Datasets

### Variable-Aperture Transform Dataset (VATD)

Kang Chen, **Shijun Yan**, Zhifeng Wang, Aiwen Jiang

**IEEE DataPort, 2025**

VATD is a real-world variable-aperture image dataset designed for learning controllable bokeh rendering. Images are captured under multiple physical aperture settings, providing paired data for studying depth-of-field and variable-aperture image transformation.

[![DBLP](https://img.shields.io/badge/DBLP-VATD-blue)](https://dblp.org/rec/data/12/ChenYWJ25)
